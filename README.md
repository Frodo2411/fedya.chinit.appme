# Федя чинит · мастер

Приложение мастера для айфона: цена клиенту под ключ, где купить деталь, сколько заработаю, журнал заказов.
Открывается в браузере и ставится на экран «Домой». Работает без VPN и без интернета (кроме журнала заказов).

## Что внутри

- **Цены.** Ищешь модель по-русски и с ошибками («айфон 14 про», «редми ноут 13», «самсунг а52»), выбираешь ремонт:
  цена клиенту по каждому варианту детали, поставщик и точное название позиции (нажми, чтобы скопировать),
  закупка, наличие, второй поставщик, заработок. «Скопировать клиенту» копирует текст только с ценами клиенту.
- **Заказы.** Журнал из твоей Google Таблицы: новый заказ прямо из цены, статусы, поиск. Без интернета изменения
  ждут на телефоне и уходят в таблицу, когда связь появится.
- **Итоги.** Месяц: принято, выдано, выручка, прибыль, расходы. Считается так же, как лист «Итоги» в таблице.
- **Проклейка.** Под деталью — какая проклейка нужна, где купить и почём: дисплей — проклейка дисплея, крышка — задней
  крышки, аккумулятор — батареи и стороны вскрытия, разъём — стороны вскрытия. Цену клиенту не меняет, вычитается из
  заработка и попадает в «Запчасть» заказа. Выключается и настраивается в «Ещё → Расчёт цены».
- **Ещё.** Обновление прайсов, настройки расчёта, текст для клиента, как заказывать у поставщиков, подключение таблицы.
- **Google Pixel.** Их нет на сайте, поэтому список моделей Pixel (от 3 до 10a) зашит в приложение (`js/data.js`).
  Детали к ним размечаются при загрузке прайса поставщика. Сверки со SmartFix и оценки iFixit у них нет,
  в файл цен для сайта они не попадают.

Расчёт цены тот же, что на сайте: работа = база × сложность (iFixit) × новизна, вверх до 5 р., не меньше 50 р.;
цена = (работа + деталь) / 0,9, вверх до 5 р.; сверка с SmartFix. Все числа меняются в «Ещё → Расчёт цены».

## Что публично, а что нет

Репозиторий открытый. Закупочные цены, поставщики и разметка деталей лежат только в `data/prices.enc`, зашифрованные
паролем (AES-256, ключ из пароля через PBKDF2, 600 000 итераций). Без пароля это набор случайных байтов.
Пароля в репозитории нет. Заказы и клиенты хранятся только в твоей Google Таблице, в репозиторий они не попадают.

## Как включить (один раз)

1. **GitHub Pages.** Репозиторий → Settings → Pages → Build and deployment: Source «Deploy from a branch»,
   Branch `claude/zealous-knuth-atmd6g`, папка `/ (root)` → Save. Через минуту-две приложение откроется по адресу
   https://frodo2411.github.io/fedya.chinit.appme/
2. **На айфоне.** Открой адрес в Safari → введи пароль → «Поделиться» → «На экран „Домой“».
3. **Google Таблица.** В приложении: «Ещё» → «Google Таблица». Там пошагово: скопировать код скрипта, вставить в
   «Расширения → Apps Script», развернуть как веб-приложение и вставить адрес. Удобнее с компьютера.

## Обновление прайсов раз в месяц

«Ещё» → «Прайсы поставщиков» → «Загрузить» у нужного поставщика → выбери файл .xlsx из «Файлов».
Приложение само найдёт столбцы названия, цены и наличия, сопоставит позиции с прошлым прайсом, новые разметит
по правилам и покажет, какие цены клиенту изменятся. Сомнительные новые позиции можно снять галочкой.
Если что-то пошло не так — «Вернуть прошлые прайсы». Обновлённый прайс сохраняется на телефоне и (зашифрованным)
на служебном листе таблицы, чтобы не потерялся.

«Файл цен для сайта» собирает `prices-models.js` для сайта: только цены клиенту, без поставщиков и закупки.

## Для разработки

- `node tests/run.mjs` — проверки на вымышленных данных; с `FC_PASSWORD=…` ещё и настоящий прайс.
- `tools/bundle.mjs` — собрать, расшифровать для правки, зашифровать обратно, сделать файл для сайта
  (пароль в `FC_PASSWORD`, подробности в начале файла).
- Расчёт (`js/engine.js`) и разбор названий (`js/rules.js`) перенесены из скриптов prais-tools один в один
  и сверены с ними на всех 4754 позициях и 1878 вариантах цен.
- После изменения файлов приложения поменяй `VERSION` в `sw.js`, иначе телефоны продолжат брать старую версию из кэша.
- `apps-script/Code.gs` — скрипт для Google Таблицы. Ключ доступа подставляет приложение при копировании кода.
