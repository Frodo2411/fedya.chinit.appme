# Федя чинит · мастер

Приложение мастера для айфона: цена клиенту под ключ, где купить деталь, сколько заработаю, журнал заказов.
Открывается в браузере и ставится на экран «Домой». Работает без VPN и без интернета (кроме журнала заказов).

## Что внутри

- **Цены.** Ищешь модель по-русски и с ошибками («айфон 14 про», «редми ноут 13», «самсунг а52»), выбираешь ремонт:
  цена клиенту по каждому варианту детали, поставщик и точное название позиции (нажми, чтобы скопировать),
  закупка, наличие, второй поставщик, заработок. «Скопировать клиенту» копирует текст только с ценами клиенту.
  Назад к поиску — свайп от левого края экрана, как в приложениях айфона; строка «‹ Поиск» закреплена сверху.
  Под названием модели — поставщики и сколько у каждого разных деталей на эту модель. Нажми на поставщика («по пути
  только он») — цены, детали, «Все детали» и заказ считаются только по его прайсу; можно выбрать нескольких,
  «Все поставщики» — как обычно. Выбор запоминается, пока он включён, это видно на экране модели и в поиске.
  Файл цен для сайта всегда считается по всем поставщикам.
  В браузере работают и его кнопка «назад», жест Safari, «назад» на Android; на компьютере — ещё и Esc.
- **Комплекс.** Несколько ремонтов одного телефона: «В комплекс» в карточке варианта. Сверху итог, скидка на работу
  второго и следующих ремонтов (20%, меняется в «Ещё → Расчёт цены»), заработок и «Скопировать клиенту».
  «Записать заказ» записывает весь комплекс одним заказом по цене со скидкой; проклейка на общую сторону вскрытия
  считается один раз.
- **Корзина.** «В корзину» у варианта детали (у проклейки — «в корзину» рядом с ней, у комплекса — «Всё в корзину»).
  Нужная ремонту проклейка (та же, что в заработке) кладётся сама и идёт за количеством детали: набор «(5шт)» —
  один на пять ремонтов, убрал деталь — ушла и её проклейка. Выключается переключателем в корзине.
  Из заказа: при «Записать заказ» из цен галочка «Детали в корзину» (выбор запоминается); в записанном заказе —
  кнопка «Детали в корзину» (детали из комментария «Деталь: …», а если их там нет — по «Неисправности» вида
  «Замена дисплея (копия)» и модели) и «Цены: модель». «Гарантия по этому заказу» предлагает «Те же детали в корзину»
  (по умолчанию выключено). В корзине у детали видно, для какого заказа.
  На вкладке «Корзина» всё разложено по поставщикам: что взять, сколько, почём, наличие, «Как заказать» и сайт.
  Нажми на название — скопируется для поиска на сайте; «Скопировать список» — текст для поставщика без цен.
  Купленное отмечается галочкой, «Другой поставщик» — купить ту же деталь у другого. Цены и наличие берутся
  из последних прайсов. Корзина хранится вместе с настройками (их копия в таблице): одна на телефоне и компьютере.
- **Заказы.** Журнал из твоей Google Таблицы: новый заказ прямо из цены, статусы, поиск. Без интернета изменения
  ждут на телефоне и уходят в таблицу, когда связь появится.
- **Гарантия.** В новом заказе сверху «Заказ / Гарантия», или в выданном заказе кнопка «Гарантия по этому заказу».
  У гарантийных своя нумерация: Г1, Г2… (обычные номера не сбиваются). Имя и телефон клиента обязательны и стоят
  первыми; можно выбрать заказ, по которому гарантия (поиск по номеру, имени, телефону, модели) — клиент и модель
  подставятся, номер запишется в столбец «Гарантия по №» (скрипт сам добавит его в конец листа). Цена 0, запчасть —
  расход: уходит в минус прибыли, в «Итогах» отдельной строкой. Фильтр «Гарантия» в списке заказов.
  Нужен скрипт таблицы версии 3 (номер «Г…» пишется и поверх формулы в «№»): «Ещё → Google Таблица → Скопировать код
  скрипта», вставить в Apps Script вместо старого, «Сохранить», Развертывание → Управление развертываниями → карандаш →
  «Новая версия» → Развернуть. Адрес скрипта на телефоне и компьютере должен быть один и тот же: в «Ещё → Google
  Таблица» видно версию скрипта и конец адреса. Со старым скриптом в «Заказах» плашка, гарантию приложение не запишет.
- **Итоги.** Месяц: принято, выдано, выручка, прибыль, расходы. Считается так же, как лист «Итоги» в таблице.
- **Проклейка.** Под деталью — какая проклейка нужна, где купить и почём: дисплей — проклейка дисплея, крышка — задней
  крышки, аккумулятор — батареи и стороны вскрытия, разъём — стороны вскрытия. Цену клиенту не меняет, вычитается из
  заработка и попадает в «Запчасть» заказа. Выключается и настраивается в «Ещё → Расчёт цены».
- **Что за деталь.** Под деталью в карточке — что значат слова в названии и что будет на этой модели: Hard/Soft OLED,
  ЖК, площадка под IC, с верификацией, HD Plus/Full HD, 60/120 Гц, переклей, снятый, «матрица orig», усиленная
  батарея, «Неизвестная деталь» (дисплей — с iPhone 11, аккумулятор — с XR/XS, камера — с 12), под заказ, гарантия
  поставщика. В «Все детали» — то же метками, чтобы сравнивать. Только для мастера, клиенту не копируется
  (`js/part-notes.js`).
  Аккумуляторы-копии для айфона: «с верификацией», «с привязкой», «без ошибки» — вариант «Копия с процентом износа»
  (процент износа в настройках виден, но отметка «Неизвестная деталь» остаётся); «подлинная деталь», Genuine,
  «зелёная галочка» — «Копия без ошибки» (новая, в настройках как оригинальная). Вариант, который не дешевле варианта
  получше, прячется под «Скрытые варианты»; «Копия без ошибки» и снятый оригинал друг друга не прячут — это выбор клиента.
  Снятый оригинальный аккумулятор: на iPhone 12 и новее после замены — «Об этом устройстве → Завершить ремонт» (iOS 18,
  нужен интернет), тогда без «Неизвестной детали» и с процентом износа; на XS–11 — только перенос данных программатором.
- **Своя деталь.** Если у поставщиков детали нет («нет деталей») или берёшь её в другом месте — во вкладке ремонта
  «+ Своя деталь»: вариант, цена детали, где взять. Цена клиенту считается по той же формуле, что для деталей из прайса.
  Хранится в настройках (и в их копии в таблице), при загрузке прайсов не обновляется, попадает в файл цен для сайта.
  Вкладки ремонтов сайта (аккумулятор, дисплей, разъём, крышка) открываются и без деталей.
- **Задняя крышка и корпус.** Всё, что у поставщика названо «Задняя крышка» или «Заднее стекло», — во вкладке
  «Задняя крышка»; в «Корпусе» — корпус и средняя часть. У айфонов, где заднее стекло снимается только лазером
  (XR–13, 8, X, SE, 14 Pro), одно стекло из прайса не считается — только крышка вместе с рамкой («Задняя крышка … + стекло»,
  по цене как корпус): телефон переезжает в новый корпус, поэтому работа и проклейки как за корпус. Так же у айфонов 5–7,
  где задняя крышка и есть корпус. Меняешь стекло лазером — своя деталь или модель в «Модели без лазера»
  («Ещё → Расчёт цены»). Пакет, сохранённый до выпуска 2026-10-28.2, переносится сам при открытии.
- **Ещё.** Обновление прайсов, настройки расчёта, текст для клиента, как заказывать у поставщиков, подключение таблицы.
- **На компьютере** (окно шире 900 px): меню слева, содержимое шире (варианты деталей в две колонки), формы — окном
  по центру, Esc закрывает окно.
- **Поставщики.** «Ещё → Прайсы поставщиков → Добавить поставщика»: название, цены в рублях или долларах (с курсом),
  есть ли наличие, сайт. Кнопка «⋯» у поставщика — изменить или удалить; новый курс сразу пересчитывает его закупку
  (курс вроде 305 вместо 3,05 или скачок больше 20% приложение переспросит).
  Название хранится только в зашифрованном прайсе на телефоне и в таблице, в открытом коде его нет. Прайс поставщика
  можно грузить в .xlsx, старом .xls или .csv. Если поставщик пишет «ОРИГИНАЛ» как уровень качества копии, а настоящий
  оригинал помечает «ОРИГИНАЛ 100%», «-СЕРВИС», «SERVICE PACK», «-СНЯТЫЙ», «-ПЕРЕКЛЕЙ», — приложение понимает это
  по названиям в прайсе (переключатель «„ОРИГИНАЛ“ у поставщика — уровень копии» в «⋯»): простой «оригинал» у него —
  копия. Новый оригинальный аккумулятор Apple у поставщиков не бывает (только снятый), поэтому «оригинал» у нового
  аккумулятора айфона — копия, а с привязкой или «подлинная деталь» — «копия без ошибки». Разметка в данных остаётся
  как была, поправка делается при расчёте (`fixTier` в `js/rules.js`).
  Наличие отметками «+»/«-» по складу и магазинам: в наличии, если «+»
  хоть где-то в Минске (столбцы других городов не учитываются). Если в репозиторий потом выложить прайс с более
  поздней датой, добавленные на телефоне поставщики пропадут — их прайс надо будет загрузить снова.
- **Телефоны, которых нет на сайте** (около 800: Google Pixel, Tecno, Infinix, Vivo, OPPO, OnePlus, Honor, старые
  iPhone и Samsung, ZTE, TCL, Oukitel, Blackview и др.) — в `js/models-app.js`: бренд, модель, год выхода и другие
  названия у поставщиков. Там же другие названия моделей сайта (`SITE_ALIASES`: «Pocophone F1», коды Samsung и т.п.). Детали к ним размечаются при загрузке
  прайса поставщика. Сверки со SmartFix и оценки iFixit у них нет; в файл цен для сайта попадают, если есть цена.
- **Ремонты по любой детали из прайса.** Кроме аккумулятора, дисплея, разъёма и крышки (как на сайте) — задняя и
  фронтальная камера, громкий и слуховой динамик, вибромотор, сканер отпечатка, шлейф кнопок, межплатный и другие шлейфы, корпус,
  стекло камеры, SIM-лоток, тачскрин, стекло экрана под переклейку. Показываются, только если для модели есть деталь.
  Работа (база) подобрана по прайсам сервисов Минска (октябрь 2026) в той же шкале, что аккумулятор и дисплей; у лёгких
  ремонтов (SIM-лоток, стекло камеры, динамики) свой минимум за работу, иначе цена выше рынка. Всё меняется в
  «Ещё → Расчёт цены». Задняя камера по умолчанию — самый дорогой модуль (основной), остальные — в «Все детали».
  Защитные стёкла, рамки дисплея, расходники и инструмент ремонтом не считаются. На сайт попадают все ремонты с ценой.

Расчёт цены тот же, что на сайте: работа = база × сложность (iFixit) × новизна, вверх до 5 р., не меньше 50 р.;
цена = (работа + деталь) / 0,9, вверх до 5 р.; сверка с SmartFix. Все числа меняются в «Ещё → Расчёт цены».

## Что публично, а что нет

Репозиторий открытый. Закупочные цены, поставщики и разметка деталей лежат только в `data/prices.enc`, зашифрованные
паролем (AES-256, ключ из пароля через PBKDF2, 600 000 итераций). Без пароля это набор случайных байтов.
Пароля в репозитории нет. Заказы и клиенты хранятся только в твоей Google Таблице, в репозиторий они не попадают.

## Как включить (один раз)

1. **GitHub Pages.** Репозиторий → Settings → Pages → Build and deployment: Source «Deploy from a branch»,
   Branch `claude/zealous-knuth-atmd6g`, папка `/ (root)` → Save. Через минуту-две приложение откроется по адресу
   https://frodo2411.github.io/fedya.chinit.appme/
2. **На айфоне.** Открой адрес в Safari → введи пароль → «Поделиться» → «На экран „Домой“».
3. **Google Таблица.** В приложении: «Ещё» → «Google Таблица». Там пошагово: скопировать код скрипта, вставить в
   «Расширения → Apps Script», развернуть как веб-приложение и вставить адрес. Удобнее с компьютера.

## Обновление прайсов раз в месяц

«Ещё» → «Прайсы поставщиков» → «Загрузить» у нужного поставщика → выбери файл .xlsx или .xls из «Файлов».
Приложение само найдёт столбцы названия, цены и наличия, сопоставит позиции с прошлым прайсом, новые разметит
по правилам и покажет, какие цены клиенту изменятся. Сомнительные новые позиции можно снять галочкой.
Цвета одной детали считаются одной позицией, цена клиенту — по самому дорогому цвету.
Если что-то пошло не так — «Вернуть прошлые прайсы». Обновлённый прайс сохраняется на телефоне и (зашифрованным)
на служебном листе таблицы, чтобы не потерялся.

«Файл цен для сайта» собирает `prices-models.js` для сайта: только цены клиенту, без поставщиков и закупки.
«Обновить цены на сайте» отправляет этот файл прямо на хостинг сайта (hoster.by): в приёмник prices-update.php рядом
с index.html, по ключу сайта (в PHP лежит только его SHA-256). Если задан ещё ключ GitHub (fine-grained token только для
Frodo2411/fedya.chinet, Contents — Read and write), копия файла кладётся и в репозиторий сайта. Ключи хранятся только
на телефоне (в таблицу не копируются), поменять — «Ключи для сайта».

## Для разработки

- `node tests/run.mjs` — проверки на вымышленных данных; с `FC_PASSWORD=…` ещё и настоящий прайс.
- `tools/bundle.mjs` — собрать, расшифровать для правки, зашифровать обратно, сделать файл для сайта
  (пароль в `FC_PASSWORD`, подробности в начале файла).
- Расчёт (`js/engine.js`) и разбор названий (`js/rules.js`) перенесены из скриптов prais-tools один в один
  и сверены с ними на всех 4754 позициях и 1878 вариантах цен.
- После изменения файлов приложения поменяй `VERSION` в `sw.js`, иначе телефоны продолжат брать старую версию из кэша.
  То же значение — в `APP_VERSION` (`js/view-more.js`): его видно в «Ещё → Приложение», тест проверяет, что они совпадают.
- `apps-script/Code.gs` — скрипт для Google Таблицы. Ключ доступа подставляет приложение при копировании кода.
